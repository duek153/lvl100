# LVL100 · הדרך ל-100

אתר הכנה לאמירנט (לשעבר אמיר"ם) שמרגיש כמו משחק. יש בו XP, רמות, Streak, Boss Battles, Daily Quest, Leaderboard, חזרה מרווחת (Spaced Repetition), קושי אדפטיבי וסימולציה במבנה העדכני של הבחינה.

🌐 **לשימוש:** https://duek153.github.io/lvl100/

> **שם זמני:** LVL100 ("Level 100"). כדאי לבדוק זמינות של סימן מסחר ודומיין לפני השקה.

## הרצה

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 557 בדיקות: לוגיקה + ולידציה של כל התוכן
npm run build      # build סטטי ל-dist/ (אפשר לארח בכל מקום, HashRouter)
```

## מה יש ב-MVP
- **Onboarding** (6 מסכים), ואחריו **מבחן מיקום** אדפטיבי של 20 שאלות: רמה, ציון משוער, חוזקות וחולשות
- **Dashboard**: ציון נוכחי מול יעד, משימת היום, המשך מסלול, סטטיסטיקות, תוכנית יומית ו-Leaderboard
- **הדרך שלי ל-100**: 9 שלבים עם Boss לכל שלב, ומבחני התקדמות ב-Level 5/10/15
- **אוצר מילים**: 514 מילים, Flashcards, SRS, Weak Words ומאגר עם חיפוש
- **דקדוק**: 11 נושאים (הסבר → Practice → Challenge → Mastery), 115 שאלות
- **קריאה**: 50 אנסינים מקוריים (10 מהם באורך מבחן, עם 5 שאלות)
- **שאלות בסגנון הבחינה**: 116 השלמת משפטים, 42 מילים נרדפות, 45 ניסוח מחדש, ועוד 1,028 שאלות מילים שנוצרות מהמאגר
- **Daily Challenge**, תזכורות (Web Notifications, באנר בתוך האתר וקובץ ‎.ics ליומן), מסך מוכנות, **סימולציית אמירנט** (נפתחת לפי 6 מדדים)
- **My Progress** עם גרפים, הישגים, אתגר חבר דרך קישור, Dark Mode, תנועה מופחתת, Admin בסיסי

## ארכיטקטורה
ראו [`docs/PLAN.md`](docs/PLAN.md): המחקר על הבחינה ומקורותיו, ה-DB, העמודים, ה-User Flow וה-Phases.

- `src/domain/`: לוגיקה טהורה ונבדקת (XP, levels, streak, SRS, adaptive, IRT scoring, simulation, readiness)
- `src/services/game.ts`: כל מעברי המצב. זה הקוד שעובר לשרת
- `src/store/repository.ts`: ממשק `Repository`. כרגע LocalStorage, מפתח נפרד לכל "טבלה"
- `src/data/`: תוכן ב-chunks שנטענים לפי דרישה. `src/data/exam.ts` הוא המקום היחיד לעובדות על הבחינה
- `supabase/schema.sql`: טבלאות מנורמלות, RLS, ו-RPC לניקוד בצד השרת

## חשוב לדעת
- **הציון המשוער הוא אומדן פנימי**, לא ציון של מאל"ו. זה מוצג בכל מקום שבו מופיע ציון.
- `nite.org.il` היה חסום בסביבת הפיתוח. העובדות אומתו דרך תוצאות החיפוש של עמודי מאל"ו, ומה שנמצא רק במקורות משניים מסומן ⚠️ במסך "על המבחן" וב-`exam.ts`. **צריך לאמת ידנית לפני השקה.**
- כל השאלות והאנסינים מקוריים. חומרי מאל"ו מיועדים לשימוש אישי בלבד, ולכן האתר רק מפנה אליהם.
- ב-MVP ה-Leaderboard משתמש ביריבים מדומים (מסומנים ככאלה). Leaderboard אמיתי וחיפוש חברים דורשים Supabase.
- בלי Backend, הנתונים נשמרים בדפדפן. אפשר לייצא ולייבא גיבוי במסך ההגדרות.
